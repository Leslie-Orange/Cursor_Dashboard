# Cursor 额度仪表盘 macOS 1.5.1 验证记录

日期：2026-10-23（北京时间）。版本 1.5.1，build 7；本机系统 macOS 27.0.1。

## 修复与数据口径

周额度接口实际返回 `planUsage.totalPercentUsed = 100`；旧网页月度摘要同时返回 `used = 0`、`limit = remaining = 4615`。1.5.0 混用了旧月度金额，覆盖真实周用量，误显示剩余 100%。

1.5.1 对周套餐只采用当前周期接口的总已用百分比，剩余值为 `100 - totalPercentUsed`。不再采用 Auto 独立池或旧月度摘要作为周总额度；总用量缺失时显示未知。旧月套餐原有路径保留。

快照格式升级为 3。旧周快照中的主额度和详情失效，额外池余额仍保留；新周快照中的真实零值正常保存。旧月快照继续兼容。
