# Windows 托盘修复说明（Grok CLI 执行）

模型：grok-4.7 + reasoning effort xhigh
（会话尝试通过 GROK_CONFIG_PATH 请求 1M context_window；CLI 模型目录不支持 `-m "grok-4.7 1M"` 字面量）

## 1. 托盘图标
- `TrayIconFactory.Create`：去掉近黑底盘，改为浅色磨砂圆盘 + 青/薄荷绿描边 + 高光弧
- 仍显示主/副额度短数字，颜色仍走 GlassTheme.Emphasis

## 2. 右键菜单
- 取消 NotifyIcon 内置 ContextMenuStrip 自动弹出（避免与手动 Show 双开）
- 右键 MouseUp 调用 ShowTrayContextMenu：对 NotifyIcon 隐藏窗口 SetForegroundWindow，再 Show 菜单，并 PostMessage WM_NULL
- 解决「首次右键菜单无法选中，需先左键一次」的问题

- `build-win.ps1` 编译通过，已更新 CursorQuotaPet.exe
