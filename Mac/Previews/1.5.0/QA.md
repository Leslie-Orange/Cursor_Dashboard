# Cursor 额度仪表盘 macOS 1.5.0 验收记录

验收日期：2026-10-22 22:39（北京时间）。版本 1.5.0，build 6；原地修改 Mac 项目，Windows 未修改。

## 最终界面

- 应用图标为石墨黑底、暖白几何立方体、双灰度额度条，完整 ICNS 使用逐尺寸矢量渲染。
- 菜单栏保持双行，第二行名称为“额外”；图标、文字和空白处的点击均由父视图统一处理。
- 详情主卡显示“周限额”，额外卡显示“额外额度池”；两处重复标题已移除。实际旧月套餐使用“月限额”。
- 正常数字为系统石墨/白色，进度条为中性灰；≤30% 橙色、≤10% 红色。额外卡使用两位小数显示“余额 / 总额”。
- 周限额使用 includedUsagePeriod 与 includedUsageResetsAt；额外金额直接读取信用池或预付额度的美分字段，不从旧百分比反推。
