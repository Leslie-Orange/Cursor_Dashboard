# Windows 1.5.1 验证记录

日期：2026-10-30（北京时间）。参照远端 main 的 macOS 1.5.1；Windows 程序及安装包版本 1.5.1.0。

## 刷新故障与修复

本机 Cursor 3.27.22 把 `cursorAuth/accessToken` 保存为 `cursor-safe-storage:v1:` 包装的 Electron safeStorage 密文。旧仪表盘将该存储值直接作为 Bearer 发送，接口返回 401；重新登录无法解决读取格式不兼容。

已根据当前 Cursor 客户端的存储编码逻辑，使用当前 Windows 用户 DPAPI 解封 Cursor 的本地密钥，再通过 Windows BCrypt AES-GCM 解码 v10 载荷。令牌及密钥仅在内存使用，不保存或输出。旧明文登录态继续兼容；无法解码的凭据会跳过。

同步修正周额度来源、额外池金额、凭据回退、并发刷新、请求预算和失败提示。主额度缺失而额外池可用时显示「部分」，不标为完整实时数据。SQLite 凭据读取按数据库批量加载，避免每个键重复读整库。
